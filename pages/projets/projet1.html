Déploiement de GLPI intégré à un domaine Active Directory

Monter de zéro un petit SI d'entreprise en lab : un domaine Active Directory, un serveur GLPI sous Debian relié à l'annuaire en LDAPS, l'inventaire automatique des postes et des GPO pour tout distribuer.

Cadre
BTS SIO · lab virtualisé
Solution
GLPI + GLPI Agent
Finalité
Centraliser le support et le parc
  • GLPI
  • Windows Server 2025

  • MariaDB

Contexte & problématique

Reproduire l'environnement d'un service informatique : un outil de ticketing et de gestion de parc branché sur l'annuaire de l'entreprise, pour que les utilisateurs s'y connectent avec leur compte de domaine et que les postes remontent tout seuls dans l'inventaire.

La difficulté principale : l'AD refuse les connexions LDAP non chiffrées, il a donc fallu mettre en place LDAPS avec un échange de certificat entre le contrôleur de domaine et le serveur Debian.

Environnement

  • Windows Server 2025 : AD DS, DNS, DHCP
  • Client Windows 11 joint au domaine
  • Serveur Debian : Apache, PHP, MariaDB
  • Réseau de lab avec plan d'adressage dédié

Démarche

  1. Préparer le lab : machines virtuelles, adressage IP, nommage.
  2. Installer AD DS, DNS et DHCP sur le Windows Server, puis joindre le client Windows 11 et le serveur Debian au domaine.
  3. Installer la stack GLPI sur Debian (Apache, PHP, MariaDB), configurer le VirtualHost et terminer l'assistant web.
  4. Sécuriser l'installation : suppression du dossier install/ et durcissement de base.
  5. Relier GLPI à l'annuaire en LDAPS : certificat du contrôleur de domaine, confiance côté Debian, import des utilisateurs.
  6. Activer l'inventaire : plugin et GLPI Agent sur les postes, déployé par script de démarrage GPO.
  7. Créer les GPO utilisateurs (raccourci GLPI, lecteur réseau) et valider avec gpupdate /force.

Résultat

GLPI opérationnel : authentification avec les comptes AD via LDAPS, postes inventoriés automatiquement, raccourci et lecteur réseau déployés par GPO. Le paramétrage ITSM (catégories ITIL, gabarits, SLA) est en place.

Compétences mobilisées

  • Administration Linux et stack web
