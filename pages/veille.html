Les failles de sécurité majeures, 2025 – 2027

Je suis les failles dont on a le plus parlé et qui ont été réellement exploitées. Pour chacune : ce qui s'est passé, en mots simples, et ce que ça change pour les postes et les services que je gère.

Les mots à connaître

Faille (CVE)
Une erreur dans un logiciel qui permet de l'attaquer. Chacune reçoit un identifiant public, la CVE.
Gravité (CVSS)
Une note sur 10. Au-dessus de 9, la faille est critique.
Zero-day
Une faille exploitée avant que l'éditeur ait publié un correctif.
Catalogue KEV
La liste tenue par l'agence américaine CISA des failles réellement exploitées.

Ce qui s'est passé

  1. 2025

  2. CitrixBleed 2

    Citrix NetScaler

    Juin 2025

    CVE-2025-5777 · CVSS 9,3

    Exploitée
    Ce qui se passe

    Sur les passerelles d'accès à distance Citrix, un attaquant sans compte lit la mémoire de l'équipement et y vole les jetons de session. Il reprend ainsi la session d'un utilisateur déjà connecté, sans passer par la double authentification.

    Pour moi

    Les utilisateurs que j'équipe pour un client passent par ce type de passerelle. Mettre à jour ne suffit pas : il faut aussi fermer les sessions ouvertes, qui ont pu être volées.

    Source : The Register, ajout au catalogue KEV

  3. ToolShell

    SharePoint (serveurs internes)

    Juillet 2025

    CVE-2025-53770

    Zero-day
    Ce qui se passe

    Une suite de failles permet de prendre le contrôle d'un serveur SharePoint sans compte. Elle contourne un correctif publié peu avant. Des administrations et des entreprises du monde entier ont été attaquées.

    Pour moi

    Seul SharePoint installé sur ses propres serveurs était touché, pas SharePoint Online de Microsoft 365. Premier réflexe : vérifier si on est concerné avant d'agir.

    Source : SecurityWeek

  4. Pare-feu Cisco ASA

    Cisco ASA et Firepower

    Septembre 2025

    CVE-2025-20333 · CVSS 9,9

    Zero-day
    Ce qui se passe

    Deux failles enchaînées permettent de contourner l'authentification du VPN de ces pare-feu, puis d'y exécuter du code avec tous les droits. L'agence américaine CISA a ordonné aux administrations de corriger en urgence.

    Pour moi

    Un pare-feu ou un VPN exposé sur Internet est la première cible : appliquer le correctif dès sa sortie, puis vérifier que l'équipement n'a pas déjà été compromis.

    Source : BleepingComputer

  5. WSUS

    Windows Server

    Octobre 2025

    CVE-2025-59287 · CVSS 9,8

    Exploitée
    Ce qui se passe

    Le service de Windows Server qui distribue les mises à jour (WSUS) pouvait être pris en main à distance, sans compte. Le premier correctif était incomplet : Microsoft en a publié un en urgence le 23 octobre, et les attaques ont commencé le lendemain.

    Pour moi

    WSUS met à jour tout le parc : s'il est compromis, tous les postes le sont. Il ne doit jamais être joignable depuis Internet, et ce correctif s'applique sans attendre le calendrier habituel.

    Source : Infosecurity Magazine

  6. React2Shell

    React et Next.js (sites web)

    Décembre 2025

    CVE-2025-55182 · CVSS 10

    Exploitée en quelques heures
    Ce qui se passe

    Une seule requête suffit pour exécuter du code sur un serveur qui utilise les composants serveur de React, comme beaucoup de sites Next.js. Des groupes d'attaquants l'ont exploitée quelques heures après sa publication, notamment pour installer des mineurs de cryptomonnaie.

    Pour moi

    Un site web hébergé par l'entreprise est aussi une porte d'entrée : il faut savoir quelles applications web tournent, et sur quelles briques, pour savoir vite si on est concerné.

    Source : Kaspersky Securelist

  7. 2026

  8. Copy Fail

    Noyau Linux

    Avril 2026

    CVE-2026-31431

    Exploitée dès le lendemain
    Ce qui se passe

    Un utilisateur sans droits devient administrateur (root) sur presque toutes les versions récentes de Linux. L'attaque est fiable, et elle a été utilisée le lendemain de la publication de la faille.

    Pour moi

    Mettre à jour le noyau des serveurs Debian et Ubuntu, puis les redémarrer. En attendant, on peut désactiver le module concerné (algif_aead).

    Source : Qualys

  9. Citrix NetScaler, encore

    Citrix NetScaler

    Septembre 2026

    CVE-2026-88771 · 88772

    Zero-day
    Ce qui se passe

    Deux failles permettent d'exécuter du code à distance sur les mêmes passerelles Citrix. Elles étaient exploitées avant le correctif publié le 27 septembre.

    Pour moi

    Le même équipement, deux années de suite. Ce qui est exposé sur Internet (VPN, passerelles d'accès) est la première cible : c'est ce qu'il faut corriger en premier.

    Source : IT-Connect

  10. Ivanti Connect Secure

    Boîtiers VPN Ivanti

    Octobre 2026

    CVE-2026-104935 · 111357 · 118527

    Exploitées
    Ce qui se passe

    Trois failles sur ces boîtiers VPN permettent d'exécuter du code à distance et d'obtenir plus de droits. Le CERT-FR demande d'isoler le boîtier, de chercher une compromission, et de considérer comme volés tous les secrets qu'il contient.

    Pour moi

    Ces boîtiers sont reliés à l'Active Directory : s'ils sont compromis, il faut aussi changer les mots de passe des comptes de service qu'ils utilisent, pas seulement les mettre à jour.

    Source : CERT-FR, alerte CERTFR-2026-ALE-013

  11. PHP2Shell

    PHP

    Octobre 2026

    CVE-2026-109618 · 109619

    Exploitation constatée
    Ce qui se passe

    Deux failles de PHP permettent d'exécuter du code à distance sans compte, sur toutes les versions non mises à jour. Des détails ont fuité avant le correctif du 21 octobre, et le CERT-FR a constaté des tentatives d'attaque.

    Pour moi

    GLPI, l'outil de tickets que j'utilise, est écrit en PHP. Je vérifie la version de PHP de chaque serveur web : seule la mise à jour protège vraiment.

    Source : CERT-FR, alerte CERTFR-2026-ALE-014

  12. Frigos des supermarchés

    Équipements connectés

    Oct. – nov. 2026

    Faille non publiée

    Attaque
    Ce qui se passe

    Les systèmes qui règlent à distance la température des frigos de grandes enseignes ont été attaqués, le 12 octobre en France puis début novembre en Belgique, au Luxembourg et en Suède. Des denrées ont été jetées.

    Pour moi

    Un équipement industriel connecté est aussi une porte d'entrée. Il faut le placer dans son propre réseau (VLAN) et contrôler les accès à distance des prestataires.

    Source : France 24

  13. 2027

  14. Suivi en cours

    Jusqu'à l'examen

    2027
    Ce qui se passe

    Les nouvelles failles majeures de 2027 seront ajoutées ici au fil de l'année.

    Pour moi

    Même méthode : vérifier si on est concerné, puis corriger dans le bon ordre.

Ma méthode

  1. Vérifier si on est concerné : quel produit, quelle version, est-il exposé sur Internet ?
  2. Corriger d'abord ce qui est exploité, même si une autre faille a une note plus haute.
  3. Préférer la mise à jour au contournement, qui ne protège qu'en partie.
  4. Chercher des traces d'intrusion après coup : sessions ouvertes, journaux.

Mes sources de référence

  • CERT-FR : les alertes officielles françaises (ANSSI).
  • Catalogue KEV de la CISA : les failles réellement exploitées. En 2025, il en a ajouté 245 (bilan Cyble).

Ce que j'en retiens : les attaquants visent d'abord ce qui est exposé sur Internet, et ils exploitent les failles de plus en plus vite, parfois le lendemain. Mon rôle de technicien : savoir vite si nous sommes concernés, et corriger dans le bon ordre.
